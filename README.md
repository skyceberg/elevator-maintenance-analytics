## Название проекта: Elevator Operations Analytics Engine.

# Описание: «Система управления жизненным циклом технического обслуживания лифтового оборудования. Разработана для минимизации простоев и прозрачного контроля бюджетов».

# Проблема: «Высокий уровень неопределенности в процессах обслуживания, отсутствие инструментов для автоматизации отчетов и контроля SLA».

# Мое решение: «Разработана модель данных (см. schema.dbml), позволяющая отслеживать статус ремонтов, финансовые потоки и нагрузку на персонал».

# Результаты: «Система позволила сократить время подготовки и согласования финансовых документов и обеспечила прозрачность документооборота».

## Архитектура системы

Для систематизации данных была спроектирована реляционная модель базы данных, которая позволяет отслеживать взаимосвязи между объектами (лифтами), персоналом и техническими инцидентами.

![Схема базы данных](db_schema.png)

Данная модель обеспечивает:
- **Целостность данных:** привязка каждого ремонта к конкретному лифту и механику.
- **Масштабируемость:** возможность ведения учета для неограниченного парка оборудования.
- **Прозрачность:** статус каждой заявки (ремонта) является отслеживаемым атрибутом.
